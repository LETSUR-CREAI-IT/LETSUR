# 수집 일정 변경 기록

## 2026-10-09 — 하루 4회에서 하루 1회로 변경

사용자 지시에 따라 Market collection의 예약 수집을 하루 4회에서 하루 1회로 줄였다. UTC cron은 `17 0,6,12,18 * * *`에서 `17 0 * * *`로 바뀌었으며, 기존 시각 중 하나인 **한국 시간 매일 09:17**을 유지한다.

GitHub Actions 수동 실행은 계속 가능하다. 예약 실행은 GitHub 사정으로 늦어지거나 누락될 수 있으며, 이 설정 변경만으로 시간대별 가격 판정 문제가 해결됐다고 볼 수 없다. 예약 firing은 아직 관찰하지 않았다.

하루 4회 실행과 90일 보관량 관련 과거 기록은 당시 기준의 이력으로 유지한다. 현재 artifact 보관 설정은 90일이다.
