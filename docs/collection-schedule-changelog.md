# 수집 일정 변경 기록

## 2026-11-06 — 09:17에서 02:17로 당김

박건 지시('새벽으로 당겨줘')로 UTC cron을 `17 0 * * *`(한국 시간 09:17)에서 `17 17 * * *`(한국 시간 02:17)로 바꿨다. 09:17 예약은 10/27~11/5의 10번 모두 한국 시간 14:14~15:57에 시작했다(5~6.5시간 늦음, 점점 늦어지는 추세). 그래서 아침에 여는 화면이 전날 오후 자료였고, 렛서가 바란 '수집 실패를 아침에 먼저 보이게'(결정 기록 29절)와 어긋났다. 11/6에는 14:27 KST까지 예약 실행이 시작되지 않았다.

02:17로 당겨도 GitHub가 시작을 늦추거나 누락할 수 있다. 지금 정도로 늦어지면 아침 전에 끝날 것으로 보지만, 실제 시작 시각은 다음 예약부터 Actions 기록으로 확인한다. 대시보드의 '오늘'은 빌드 시각의 한국 날짜(build.py)라 새벽 실행도 그날 날짜로 계산된다. 수동 실행, 실패 판정, 실패 메일, artifact 보관 기간은 바꾸지 않았다.

## 2026-10-09 — 하루 4회에서 하루 1회로 변경

사용자 지시에 따라 Market collection의 예약 수집을 하루 4회에서 하루 1회로 줄였다. UTC cron은 `17 0,6,12,18 * * *`에서 `17 0 * * *`로 바뀌었으며, 기존 시각 중 하나인 **한국 시간 매일 09:17**을 유지한다.

GitHub Actions 수동 실행은 계속 가능하다. 예약 실행은 GitHub 사정으로 늦어지거나 누락될 수 있으며, 이 설정 변경만으로 시간대별 가격 판정 문제가 해결됐다고 볼 수 없다. 예약 firing은 아직 관찰하지 않았다.

하루 4회 실행과 90일 보관량 관련 과거 기록은 당시 기준의 이력으로 유지한다. 현재 artifact 보관 설정은 90일이다.
