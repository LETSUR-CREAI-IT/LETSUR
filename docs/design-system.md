# 대시보드 디자인 기준

`scripts/market_collection/dashboard/template.html`의 색·모서리·간격·글자·가격 추이 그래프 규칙이다. 값은 이 문서가 정하고, 템플릿 CSS의 `:root` 토큰과 `tests/market_collection/test_dashboard.py`의 `test_template_css_keeps_to_the_design_scales`가 따른다. 그래프 데이터와 화면 구성은 [dashboard.md](dashboard.md)에 있다.

## 결정

2026-10-30 박건 결정. 같은 kimi-k3 실제 수집값으로 그린 후보를 라이트·다크로 비교해 골랐다.

- 화면: C 넉넉한 카드형. 카드는 테두리 없이 바탕색 차이로 나누고, 모서리 16, 버튼·탭은 알약 모양, 숫자 칸의 값은 26px이다. A 정돈형, B 촘촘한 분석형은 쓰지 않는다.
- 그래프: 3번 '낮은 채도 + 올리면 강조'. 다른 공급자 선을 회색으로 두면 모르는 정보처럼 보여서, 공급자마다 고유 색을 쓰되 채도를 낮췄다. 마우스를 올리면 가장 가까운 선이 진해지고 그 날의 모든 공급자 가격이 싼 순서로 뜬다.
- 테마: 지금의 검정·민트와 Pretendard를 그대로 쓴다. 네이비·골드, 종이·플럼, 화이트·바이올렛 후보는 쓰지 않는다.
- 퍼센트: 같은 조건 최저가 대비로 쓴다(아래 '퍼센트').
- 선택 묶음(같은 날 이어서 결정): 기간·가격 조건·항목 버튼이 모두 같은 모양이라 어디까지가 한 묶음인지 보이지 않았다. 묶음마다 한 줄에 이름을 앞에 두고(C안) 묶음 테두리를 두른다(A안). 한 줄에 다 들어가지 않는 묶음은 누르면 펼쳐지는 목록으로 고른다(조건이 10개인 gpt-6-astra 예시).
- 그래프가 단순해졌다는 지적(같은 날): 다른 선의 변동 점을 지웠더니 자주 바뀌는 선(kimi-k3의 relace·wafer, 2주에 변동 12·14번)이 조용한 선처럼 보였다. 변동 점을 모든 선에 되살리고(원래 색), 처음 보이는 탭과 시간축 여백을 고쳤다. 데이터는 그대로였다(그래프 점 1,631개, 10/16부터).

## 색

역할로 쓴다. 상태 색은 그래프 선이나 장식에 쓰지 않는다.

| 토큰 | 역할 |
|---|---|
| `--bg`, `--surface`, `--surface-2` | 페이지 바탕, 카드, 카드 안 칸(숫자 칸·비교 조건 줄·분할 버튼) |
| `--ink`, `--body`, `--muted` | 제목·숫자, 본문, 설명·축 눈금(`--muted`는 흰 바탕에서 5.4:1) |
| `--line`, `--line-strong` | 표 줄, 입력칸 테두리와 강한 구분선 |
| `--mint`, `--mint-ink`, `--mint-soft` | 렛서 경로, 검토, 선택됨 |
| `--amber`, `--amber-soft` | 확인 필요, 주의 |
| `--slate`, `--slate-soft` | 관측 유지, 참고 |
| `--grey-soft` | 기록, 값 없음 |
| `--up`, `--down` | 가격 인상(▲), 인하(▼). 방향 표시에만 쓴다 |
| `--nav`, `--nav-ink` | 머리줄 바탕, 그 위 글자와 선택된 화면 탭 |

## 모서리

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--r-xs` | 4px | 범례 선, 표 안 작은 태그, 막대 끝 |
| `--r-s` | 6px | 칩·배지(상태, 날짜, 캘린더 일정) |
| `--r-m` | 10px | 목록 줄, 입력칸·선택칸, 캘린더 칸, 안내 상자 |
| `--r-l` | 12px | 숫자 칸, 카드 안 상자, 떠 있는 정보 상자·툴팁 |
| `--r-xl` | 16px | 카드 |
| `--r-pill` | 999px | 버튼, 화면 탭, 기간·조건·비교 선택, 필터 칩 |

이 밖에는 0과 원형 점(50%)만 쓴다.

## 간격

padding·margin·gap은 4px 단위로 쓴다. 2px은 칩 안처럼 아주 좁은 틈에만 쓴다.

- 카드 안 여백 20, 폭 640px 이하 16. 변화 상세는 24(폭 940px 이하 20).
- 카드 사이 16. 숫자 칸 사이 12.
- 표 칸 여백 8·12, 공급사 비교 표는 8.

## 글자

Pretendard Variable. 크기는 11, 12, 13, 14, 15, 18, 22, 26px만 쓴다.

| 크기 | 쓰는 곳 |
|---|---|
| 26 | 숫자 칸의 값, 요약 숫자, 상세의 핵심 변화 |
| 22 | 화면 제목, 상세 제목 |
| 18 | 모델 이름, 상세 소제목, 폰의 상세 제목 |
| 15 | 본문 기본, 카드 제목, 목록 제목 줄 |
| 14 | 접는 구역 제목, 수집 상태·공급로 현황 소제목 |
| 13 | 표, 버튼, 안내 문장 |
| 12 | 라벨, 설명, 범례, 툴팁, 그래프 축 눈금 |
| 11 | 칩, 작은 태그 |

숫자는 `tabular-nums`(`.tn`)로 맞춘다.

## 구성 요소

- 카드(`.card`): `--surface` 바탕, 테두리 없음, 모서리 16, 여백 20.
- 선택 묶음(`.tctl`): 가격 추이 위의 기간·가격 조건·항목을 한 줄씩 두고 줄 앞에 묶음 이름을 적는다. 묶음은 테두리 트랙(`.seg`: `--line` 테두리, `--surface-2` 바탕, 알약, 안쪽 여백 2)으로 감싸고, 선택됨은 `--mint-soft` 바탕에 `--mint-ink` 글자다. 한 줄에 다 들어가지 않는 묶음은 누르면 펼쳐지는 목록(`.tsel`, select, 폭 480px까지)으로 바뀌고, 화면 폭이 바뀌면 다시 잰다. 비교 조건 줄의 엄격 비교·전체 관측(`.cmpmode`)도 같은 트랙이다. 필터 칩(`.mchip`)과 '전체 보기'(`.allb`)는 선택됨 색만 같다.
- 화면 탭(`.ptabs`): 검정 머리줄 위 알약. 선택됨은 흰 바탕(`--nav-ink`)에 검정 글자(`--nav`)로, 라이트·다크가 같다.
- 숫자 칸(`.tstat`): `--surface-2`, 모서리 12, 여백 12·16, 값 26px. 렛서 경로 칸(`.tstat.let`)은 `--mint-soft` 바탕에 라벨을 `--mint-ink`로 쓴다.
- 칩(`.qchip`, `.pill`, `.tg`, `.dd`, `.qs` 등): 모서리 6(상태 배지 `.qchip`·`.hst`는 알약).

## 가격 추이 그래프

- 선: 계단선 2px. 평소에는 원래 색을 바탕과 45% 섞은 낮은 채도로 그린다. 선이나 범례에 올리면 그 선이 원래 색 3px로 진해지고 나머지는 옅어진다.
- 색 순서(라이트 / 다크): 파랑 #2a78d6 / #3987e5, 주황 #eb6834 / #d95926, 바이올렛 #6250d6 / #9085e9, 노랑 #eda100 / #c98500, 자홍 #e87ba4 / #d55181, 초록 #008300 / #008300(`--s1`~`--s6`). 탭 안 선을 이름순으로 놓고 차례로 주므로 엄격 비교·전체 관측을 바꿔도 같은 선은 같은 색이다. 일곱 번째 선부터는 회색이다(탭마다 6개까지라 참고 선이 더해질 때만 생긴다).
- 색 검증(2026-10-30, dataviz `validate_palette.js`, 이웃한 순서 기준): 라이트 흰 바탕·다크 #1a1f1d 바탕 모두 통과. 민트와 청록은 렛서 경로 강조와 겹쳐 뺐고, 빨강은 주황·자홍과 정상 시각에서도 구분되지 않아(ΔE 7~13, 기준 15) 뺐다. 노랑·자홍은 흰 바탕 대비가 3:1 미만이라 이름과 가격을 범례·툴팁·표로 함께 보인다. 파랑과 바이올렛은 색각 이상 시뮬레이션에서 가깝다(ΔE 4.5, 다크 1.9). 이웃 순서가 아니어서 검증은 통과하지만, 둘이 한 탭에 있으면 이름으로 구분한다.
- 렛서 경로 선: 민트 3px에 변동마다 점, 오른쪽 끝에 값과 '렛서'. 어느 선인지는 현재 가격 표의 렛서 경로 칩과 같은 규칙(`compare.is_assumed`, 결정 17)으로 정한다. 직접 경로는 그 경로의 선이고, 중개 경로는 기록에 엔드포인트가 없으면 만든 회사가 직접 서빙하는 엔드포인트다. 경로 파일 근거가 렛서 설정·호출 확인·관리자 지정인 기록만 강조하고, 호출 추정은 강조하지 않는다. 경로 기록은 범례 아래 '렛서 경로' 줄에 적고, 중개 경로 기록의 메모('이번 호출의 하위 공급자 Decart(요청마다 바뀔 수 있음)')도 함께 둔다. 강조한 선과 실제 호출의 하위 공급자가 다를 수 있다는 점을 거기서 보인다.
- 숫자 칸: 렛서 경로 선이 있으면 맨 앞에 '렛서 경로 현재 ○○가'와 최저와의 차이('최저보다 40% 비쌈', 2배부터 '최저의 2.7배'), 다음에 '그래프 안 최저', '최근 변동 · 직전 대비', '다음 예정'이다.
- 축: 다른 선보다 크게 높은 선(가장 높은 값이 나머지 선 최고의 1.8배 초과)은 축에서 빼고 범례에 '위쪽 범위 밖'이라고 적는다. 선이 셋 이상일 때만 빼고, 렛서 경로 선은 빼지 않는다.
- 오른쪽 끝 글자: 렛서 경로 값과 그래프 안 최저 값만 적는다.
- 점: 모든 선의 변동마다 점을 둔다. 렛서 경로 선 9px, 카드가 있는 변동 8px(누르면 그 카드로 간다), 그 밖의 변동 6px이다. 점은 선과 달리 원래 색이라 선이 조용해도 바뀐 곳은 보인다. 점에 올리면 이전 값과 직전 대비 변동률이 뜬다.
- 처음 보이는 탭: 'Standard' 탭이 있으면 그 탭, 없으면 렛서 경로 선이 있는 탭, 그것도 없으면 선이 가장 많은 탭이다(kimi-k3는 fp4 · Standard).
- 시간축: 왼쪽은 첫 점 하루 전부터, 오른쪽은 기준일 다음 날까지다. 예정 값이나 앞날 메모가 있을 때만 그 뒤로 여백을 더 둔다.

## 퍼센트

- 그래프 점마다 붙던 ▲▼%는 없앴다. 오르내림은 선의 기울기로 보이고, 선마다 기준 시점이 달라 한 그래프 안에서 비교가 되지 않았다(kimi-k3 입력 2주에 변동 33곳, wafer의 10/23 하루짜리 변동이 ▲202.5%·▼66.9%).
- 툴팁은 같은 조건 최저가 대비로 쓴다. 최저 줄은 '최저', 나머지는 '+5.3%', 2배부터는 '2.7배'다. 참고 선(전체 관측에서 더해지는 조건 미정 선)은 비교하지 않고 '참고'로 둔다. 공급사 추천의 '같은 조건 최저가' 기준과 같다.
- 원공급사 정가 대비는 쓰지 않는다. 2026-10-30 빌드에서 비교 표 113개 모델 중 원공급사 직접 가격이 있는 모델은 43개였고, 그 43개에서도 다른 공급로 321줄 중 306줄(95%)이 정가와 같은 입력·출력 단가라 거의 ±0%였다. 가격 차이가 큰 오픈 모델은 원공급사 가격을 수집하지 않는다.
- 직전 대비 %는 변동 한 건을 말하는 자리에만 쓴다. 숫자 칸의 '최근 변동'·'다음 예정', 변동 점 툴팁, 카드의 원가 칩이고, 숫자 칸에는 '직전 대비'라고 적는다. 인하 알림의 10% 기준도 직전 가격 대비다.

## 확인

- 자동: `test_template_css_keeps_to_the_design_scales`가 모서리·글자 크기·간격 값을 위 범위로 제한하고, `test_the_letsur_line_is_the_one_the_price_table_marks`·`test_a_direct_route_line_is_letsurs`가 렛서 경로 선 판정을 본다.
- 화면: 변화, 모델별 가격, 수집 상태, 공급로 현황을 라이트·다크와 폭 375px에서 연다. 375px에서 페이지 가로 넘침이 없어야 한다(공급사 비교 표, 공급로 현황 표, 수집 상태 표는 구역 안에서 가로로 스크롤한다).
