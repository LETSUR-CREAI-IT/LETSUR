# 실제 자료로 확인한 알림량

※ 이 수치는 대시보드 RECORD 제외와 기한 7일 제한(2026-10-27 결정)을 넣기 전에 측정했습니다. 다시 측정하지 않았습니다.

| 검증 | 결과 |
|---|---|
| 10월 25일 실제 자료 372이벤트 | 4대상 이벤트 → 3카드 → 1메시지 |
| 10월 26일 실제 자료 395이벤트 | 4대상 이벤트 → 3카드 → 1메시지 |
| 같은 날 재실행 | 추가 발송 0 |
| 10월 26일 입력을 고정해 27~30일 미확인 유지 | 매일 1메시지 |
| 첫날 모두 확인 | 이후 0메시지 |
| 합성 긴급 카드 100개 | 9메시지 |

**현재 자료의 알림량은 적습니다. 다만 하루 총량 상한은 없어 미확인 건이 쌓이면 늘어납니다.** 마감 없는 변화가 제외되므로 전체 시장 변화가 적다는 뜻도 아닙니다.

기존 자료의 미래 일정까지 미확인으로 유지하면 12월 26일은 4카드/5이벤트, 27일은 10카드/23이벤트이며 각각 1메시지입니다. 이후 날짜의 수치는 **새 수집이 없는 가정**으로 계산했으며 미래 발생량 예측이 아닙니다. 보통 짧은 카드 12개를 한 메시지로 묶고, 긴 카드는 더 나뉠 수 있습니다.

시뮬레이션은 실제 Slack에 보내지 않았고 운영 기록도 바꾸지 않았습니다. 세부 수치와 입력 파일 해시는 `simulation-results.json`에 있습니다.

재현하려면 해당 날짜의 `events.json`을 받아 아래 경로를 바꿉니다. 원본 자료는 ZIP에 포함하지 않았습니다.

```powershell
python simulate_volume.py --source "2026-10-25=<첫 파일 경로>" --source "2026-10-26=<둘째 파일 경로>" --future-days 4
```
