# Slack 알림 기능

**긴급으로 분류된 미확인 사건과 새로 확인된 변화를 Slack으로 알립니다.** 기존 팀원 파일을 건드리지 않은 별도 검토용 사본입니다.

## 1. 어떤 알림을 보내나요?

예정 가격·조건 변경, 할인 종료, 모델 종료, 공급 경로 제거를 알립니다. 같은 사건의 입력·출력 가격 등은 카드 하나로 묶습니다. 카드에는 변경 내용, 남은 날/경과일, **확인함·대시보드 버튼**이 표시됩니다. 대시보드 버튼은 그 사건이 든 대시보드 카드로 바로 열리고, 여러 카드에 걸치면 첫 카드로 열며 ‘대시보드 카드 외 N장’을 적습니다.

## 2. 긴급성은 어떻게 판단하나요?

- **대응기간이 5일 이내**이면 긴급으로 분류합니다. 대응기간은 적용일이나 이용·할인 종료일까지 남은 날입니다.
- 기한이 이미 지났어도 미확인이면 알리지만, **기한이 7일을 넘게 지난 사건은 8일째부터 보내지 않습니다.**
- 기본은 검증된 사건입니다. 공식 출처·대상·일정이 명확하고 허용된 미확정 사유만 있는 일부 사건도 ‘미확정’ 표시로 알립니다. 매출·사용량에 따른 사업 영향은 평가하지 않습니다.
- **대시보드 판정을 따릅니다.** 같은 실행의 `cards.json`에서 추천 행동이 **기록(RECORD)**인 카드의 사건은 보내지 않습니다(2026-10-27 결정). 렛서가 쓰지 않는 경로의 변화(**NOT APPLIES**)도 보내지 않습니다(2026-10-28 가안, 그 전에는 보냈습니다).
- **새로 확인된 변화는 한 번만 알립니다(2026-10-28 가안).** 렛서 경로(APPLIES)나 사용 여부를 모르는 경로(UNKNOWN)에서 판매 중단(모델 종료, 경로 제거)이 처음 확인되면 기한이 멀어도 한 번 알리고, 기한 5일 전부터는 위 긴급 규칙으로 다시 알립니다. 기한이 없는 확정 가격 변화(이미 관측된 인상·인하)도 처음 확인될 때 한 번 알립니다. 관측된 지 7일이 넘은 변화는 보내지 않아서, 규칙을 처음 켤 때 지난 변화가 한꺼번에 가지 않습니다. `cards.json`이 없으면 이 알림은 보내지 않습니다.
- **한 메시지 안의 순서**는 판매 중단, 비용 증감, 그 밖 순이고, 같은 단계 안에서는 기한이 가까운 순입니다. 3팀 서면보고에 적힌 렛서 판단 순서(지금 쓰는 판매처 → 판매 중단 위험과 기한 → 같은 조건의 비용 증감 → 대신 쓸 판매처 → 보안·계약상 빼야 할 곳)를 따랐고, 렛서 답변 원문은 확인 전입니다. 대신 쓸 판매처와 보안·계약 기준은 렛서 신뢰 공급사 목록과 실제 경로가 오면 정합니다.
- `cards.json`을 읽지 못하면 판정 없이 기존 규칙(7일 제한 포함)으로 보내고, 메시지 머리말과 실행 결과의 `cards_warning`에 사유를 적습니다. 이 대체 동작은 팀에서 다시 정합니다.
- 모델·경로·조건·요금 항목·단위도 대시보드와 같은 이름으로 씁니다. 이름을 찾지 못하면 원래 값을 그대로 씁니다.

## 3. 알림은 어떻게 만들어지나요?

**수집 → 이벤트 생성과 분류 → GitHub에 결과 저장 → 결과 다운로드 → 긴급성·확인 여부 판단 → 카드로 묶기 → Slack 발송**

수집 예약은 매일 **09:17 KST**입니다. 10분마다 GitHub 자동 실행이 성공했는지 확인해 새 결과를 처리합니다. 현재는 수집 뒤의 배포 단계까지 성공해야 새 결과를 가져옵니다.

## 4. 실제 자료에서는 얼마나 오나요?

10월 26일 자료는 **395개 이벤트 중 4개가 대상 → 3카드 → 1메시지**였습니다. 10월 25일 자료도 발송량이 같았습니다.

위 수치는 RECORD 제외와 7일 제한을 넣기 전에 측정했습니다. 10월 27일 자료에 10월 28일 가안을 적용하면, 10월 27일에는 새 변화 1카드(glm-5.3-flash Vercel 단가 인하 3건)를 보내고 10월 28일에는 보낼 것이 없습니다. 같은 자료로 앞으로 90일을 돌려 보면 NOT APPLIES 제외로 빠지는 알림은 없고, 12월 26일부터 gemini-3.8-flash Vercel 할인 종료(12/31)를 알립니다. 입력을 고정한 시뮬레이션에서는 미확인 시 매일 1메시지, 모두 확인한 뒤에는 0메시지였습니다. 현재 양은 적지만 **하루 총량 제한은 없습니다.** 합성 긴급 카드 100개는 9메시지로 나뉩니다. ## 5. 미확인 알림은 다시 보내나요?

**매일 수집 완료 후 재알림합니다.** 기한이 지나도 7일까지 유지하며, 한 사람이 ‘확인함’을 누르면 해당 내용의 공용 재알림이 멈춥니다. 읽음·대응 완료를 뜻하지는 않습니다. 가격·일정 등 핵심 내용이 바뀌면 다시 확인 대상이 됩니다.

같은 날 동일 내용은 중복 발송하지 않습니다. 수집이 종일 없으면 23시 이후 기존 건만 재알림합니다. 전송 성공 여부가 불명확한 건은 중복 방지를 위해 보류합니다.
