# 업데이트 제안 — Slack 알림 연결

**기존 수집 결과에 아래 기능을 붙이는 제안입니다.** 별도 모듈에서 구현·테스트했으며 팀원 원본에는 적용하지 않았습니다.

| 추가한 내용 | 동작 |
|---|---|
| 긴급 알림 | 대응기간 5일 이내이거나 기한이 지난 미확인 사건을 발송합니다. |
| 수집 결과 자동 반영 | GitHub 자동 실행 결과를 10분마다 확인해 새 결과를 읽습니다. |
| 확인 버튼·재알림 | 미확인 건은 매일 보내고, ‘확인함’을 누르면 해당 내용의 재알림을 멈춥니다. |
| 중복 방지·기록 보관 | 같은 날 동일 내용을 반복 발송하지 않습니다. 확인·발송 기록은 DB(기록을 저장하는 파일)에 남아 재시작 후에도 유지됩니다. |
| Slack 앱 공유 | manifest(앱 설정 파일)로 같은 봇 설정을 다시 만들 수 있습니다. 설치·토큰 발급은 각 공간에서 진행합니다. |

실제 자료 **395이벤트 → 4대상 이벤트 → 3카드 → 1메시지**를 확인했습니다. 테스트 78개와 실제 발송·버튼·프로그램 재시작 검증을 마쳤습니다.

**팀원과 합의할 내용:** 공용 자동 실행에 이 모듈을 붙이는 위치, 취소·철회 사건의 전달 방식, 대시보드 읽음/변경 이력/개별 사건 링크입니다. 기존 정렬·필터는 수정하지 않습니다.

**운영 전 남은 일:** 노트북 테스트를 상시 실행 환경으로 옮기기, 설치할 Slack 공간·관리 담당자 정하기입니다. 자세한 규칙과 알림량은 [README](README.md)에 있습니다.
