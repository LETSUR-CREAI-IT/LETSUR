## 무엇을 추가했나

1차 중간보고 피드백("외부 정보원을 늘리기보다 사건 카드 한 건을 완성하라", "신뢰도를 하나로 합치지 말 것", "판정 불가 상태와 긴급성")에 맞춰, 외부 할인 출처 조사 결과를 사건 카드 하나에 끝까지 연결해 보여 준다.

| 추가 화면 | 들어가는 곳 | 내용 |
| --- | --- | --- |
| **외부 단서** (새 메뉴) | 상단 메뉴 `외부 단서` | 외부 단서 수집 경로 6단계(출처 받기 → 1차 거르기 → 원문 인용 → 단서 기록 → 원출처 확인 → 사건 카드 연결), 출처 범위표(지금 / 다음 / 수동 / 제외), 단서 기록 형식 7칸, 원출처 확인 항목 5가지, 적용 사례, 출처 평가 방법, DeepSeek 시간대 요금 위험 |
| **GPT-5.6 Sol 사건 카드** (새 사례) | 메인 왼쪽 `확인할 사례`의 두 번째 카드 | 피드백 7단계 순서(원문·관측 → 비교 조건 → 사건 A·B·C 생성·갱신 → 세 질문 판단 → 다음 확인과 D-day → 담당자에게 보여줄 결과 → 줄어드는 작업), 사건 시간선(Vercel 공지가 가격 상승 관측보다 35일 먼저), 외부 단서 5건 기록 |

## 원본 v13에서 바뀐 부분

추가 코드는 HTML 안에서 `[외부 단서 추가 · 기범]` 주석으로 시작과 끝을 표시했다. 원본 함수에서 고친 곳은 연결에 필요한 줄뿐이다.

| 위치 | 바뀐 내용 |
| --- | --- |
| `<title>`, 상단 설명 | 제목에 "외부 단서 추가"를 붙이고, 원본 설명 위에 추가본이라는 안내 한 줄을 넣음. 원본 설명 문장은 그대로 |
| `<style>` 끝 | 새 화면용 스타일 블록 추가. 기존 스타일 규칙은 수정하지 않음 |
| `nav()` | `외부 단서` 메뉴 추가, 현재 화면에 따라 선택 표시 |
| `main()`의 확인할 사례 | GPT-5.6 Sol 카드 추가(유형 `전체`·`LLM`에서 표시). 사례 개수를 두 카드 합으로 계산. 기존 Sunburst 카드는 그대로 |
| `render()` 앞 | `detailExt()`(GPT-5.6 Sol), `extPipeline()`(외부 단서), 데이터 `XSOL`·`XSOURCES`·`XCASES` 추가 |
| `render()` | 새 화면 두 개(`xcase`, `ext`)로 가는 분기와 위치 표시 문구 추가 |
| 클릭 처리 | `data-xcase`, `data-go="ext"` 처리 두 줄 추가 |

메인의 2×2, 알림 11건, 알림 상세, Sunburst 사례, 그래프, 밝은 안/어두운 안 동작은 바꾸지 않았다. 브라우저에서 메인 → 각 알림 상세 → Sunburst 사례 → 외부 단서 → GPT-5.6 Sol → 어두운 안, 유형 필터(전체·이미지·LLM·영상)를 차례로 열어 스크립트 오류가 없는 것을 확인했다.

## 데이터와 판단 경계

- 새 화면의 값은 **공개 출처만** 쓴다(Vercel changelog, OpenRouter 공개 API, OpenAI 문서 조건 메모, 가격 추적 사이트, 개발자 블로그). 2026-10-06 웹 조사와 직접 접속 확인 결과이며 이후 바뀔 수 있다.
- Vercel의 9/21 가격 상승은 렛서 제공 샘플에서 관측한 것이다. **샘플 값은 넣지 않았고** "렛서 샘플 관측(값 비공개)"으로만 표시했다.
- 외부 단서 수집은 **수동 조사 결과**다. 자동 수집 모듈은 `src/`나 `scripts/`에 아직 구현하지 않았다. 수집기(`scripts/market_collection/`)와 Actions 설정도 건드리지 않았다.
- 사건 A·C의 원인은 2차 자료이거나 공식 원문 확인 전이다. 화면의 담당·기한은 **제안값**이며 팀이 확정하지 않았다. 렛서 실제 사용 경로와 청구액은 확인하지 않았다.
- D-day는 작성일 2026-10-09 기준이다. 메인 화면의 가상 데이터 기준일(2026-10-06)과 다르다.

## 여는 방법

v13과 같다. 파일을 내려받거나 저장소를 clone한 뒤 HTML을 브라우저에서 연다. 별도 패키지 설치는 필요 없다. 파일을 직접 열지 못하면 저장소 루트에서 다음 명령을 실행하고 표시된 주소를 연다.

python3 -m http.server 8766 --bind 127.0.0.1
