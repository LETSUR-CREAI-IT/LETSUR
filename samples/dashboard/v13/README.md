이 작업 브랜치를 기존 clone에 받으려면 저장소 루트에서 다음 명령을 각각 실행하세요.

```sh
git fetch origin
git switch --track origin/codex/dashboard-v13-share-20261008
```

같은 이름의 로컬 브랜치가 이미 있으면 `git switch codex/dashboard-v13-share-20261008`을 실행하세요.

브라우저가 파일을 직접 열지 못하면 저장소 루트에서 아래 명령을 실행하고, 표시된 로컬 주소를 여세요.
