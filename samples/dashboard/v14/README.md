# 웹 v14 시안 (담당자 중심 재배치)

> **작성: 기범(GitHub `chunbaepak`) · 2026-10-09.** v13(박건)과 v13-external-clues(기범)의 데이터를 그대로 쓰고 화면 구성만 새로 짠 별도 시안이다. `samples/dashboard/v13/`, `samples/dashboard/v13-external-clues/`는 수정하지 않았다.

## 왜 다시 짰나

담당자가 화면을 열었을 때 "무엇을, 언제까지, 왜" 처리해야 하는지 먼저 보이도록 했다. 1차 중간보고 피드백(긴급성 반영, 신뢰도 분리, 판정 불가 상태)과 팀 논의(메인을 할 일 목록 중심으로, 2×2는 요약·필터로)를 반영했다.

## 화면 구성

| 영역 | 내용 |
| --- | --- |
| 위 · 분류 | v13의 2×2(영향도 × 신뢰도)와 평가 보류. 칸마다 건수와 가장 급한 1건을 보여 주고, 누르면 목록을 거른다 |
| 위 · 일정 캘린더 | 적용일·종료일·확인 기한을 월간 캘린더에 표시. 마우스를 올리면 요약(날짜·D-day·분류·한 문장·다음 할 일), 누르면 상세. 달 이동, 다음 일정 3건 |
| 위 · 단가 변동 | 가격이 바뀐 변화의 변동률. 인상 빨강, 인하 파랑, 0 기준 |
| 가운데 · 목록 | 분류별로 묶고 D-day가 가까운 순으로 정렬. 각 줄 맨 앞에 D-day |
| 가운데 · 상세 | 핵심 한 문장 → 다음 할 일 · 적용일 · 렛서와의 관계 → 이전/현재 가격 막대 → 확인 상태(변화 사실 · 원인 · 렛서 해당) → 근거(접힘: 바뀐 내용, 영향, 선택지, 비교, 출처, 미확인, 판정 이유) |
| 아래 · 참고 | 모델별 현황 표, 일별 감지 건수 |

모든 차트는 "표로 보기"로 같은 값을 표로 볼 수 있다. 차트 색은 색각 이상 구분과 화면 대비 기준을 검증 스크립트로 확인했다.

## 데이터와 경계

- 시연 데이터 14건: v13의 가상 모델·가격 알림. 분류(조달 검토·추가 검증·관측 유지·기록·평가 보류)는 v13 판정 규칙 결과를 그대로 옮겼다.
- 실제 3건: GPT-5.6 Sol 사건(할인 종료, 11월 인상 예고, 정가 인하). 공개 출처 값만 썼고 렛서 제공 샘플은 관측 시점만 참고했다. 렛서 사용 경로를 몰라 영향도를 판정할 수 없으므로 평가 보류로 둔다.
- 한 문장 요약, 다음 할 일, 확인 상태 문구는 각 알림 데이터를 보고 기범이 쓴 시안 문구다. 팀 확정 전이다.
- D-day는 시안 기준일 2026-10-06 기준이다. 실시간 갱신, 수집기·`signals` 결과 연결, 계정·청구 확인은 하지 않는다.

## 여는 방법

파일을 내려받아 브라우저에서 연다. 폰트·로고·데이터가 모두 들어 있어 별도 설치가 필요 없다. 파일을 직접 열지 못하면 저장소 루트에서 다음 명령을 실행하고 표시된 주소를 연다.

```bash
python3 -m http.server 8766 --bind 127.0.0.1
```

http://127.0.0.1:8766/samples/dashboard/v14/letsur-dashboard-v14.html
